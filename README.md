Gameslop is a progressive web app full of small games:

- Suguru
- Crowd Run (a clone of Count Masters)
- Gems (a clone of Bejeweled)
- Blocks (a clone of Block Blast)
- Bubbles (a clone of Puzzle Bobble)
- Minesweeper
- Pipe Connect (a clone of Flow Free)
- Takuzu (a.k.a. Binairo)
- Breakout
- 2048
- Star Battle
- Space Invaders
